LeetSync is a local-first browser extension that detects accepted LeetCode submissions and commits them to your own GitHub repository in an organized structure. It runs entirely in your browser with no telemetry. The extension observes your LeetCode session locally, collects only the problem/solution data needed to create files, and pushes commits directly to GitHub using your personal access token or OAuth (token exchange handled by a minimal Cloudflare Worker that never stores your data). Solutions go only to the repository you configure. Not affiliated with LeetCode.
